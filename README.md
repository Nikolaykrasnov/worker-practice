# WORKER — практическое задание

Консольное приложение на Java хранит сведения о сотрудниках Университета «Синергия» и выводит работников, чей стаж превышает значение, введённое пользователем.

## Требования

- JDK 17 или новее
- Maven 3.9 или новее

## Запуск

```bash
mvn clean test
mvn exec:java
```

Приложение запрашивает количество сотрудников, данные каждого сотрудника и минимальный стаж. Зарплата вводится в рублях, год поступления — четырьмя цифрами.

## Структура

- `Worker` — модель сотрудника с инкапсулированными полями, конструкторами, методами изменения и отображения данных
- `WorkerService` — отбор сотрудников по стажу
- `Main` — ввод данных, проверка значений и вывод результата
- `WorkerServiceTest` — автоматические тесты основной логики
